1.A

1. Kaj je OS?
To je temeljna programska oprema, ki deluje kot vmesnik med uporabnikom in strojno opremo računalnika, omogoča zagon aplikacij ter upravlja vire, kot so procesor, pomnilnik (RAM) in trdi disk. Brez njega računalnik ne more delovati. Najbolj znani primeri so Windows, Linux, macOS, Android in iOS.

2. Tri naloge?
Časovno razporejanje opravil,
Reševanje konfliktnih situacij (sočasni dostopi do virov),
Optimizacija in nadzira uporabe virov.

3. Windows/Linux/macOS- razlike
Windows je zaprtokodni operacijski sistem podjetja Microsoft, ki deluje na skoraj vseh računalnikih in je najbolj razširjen, zato ima največjo podporo programov in iger, vendar je zaradi svoje razširjenosti tudi pogostejša tarča zlonamerne programske opreme.

Linux je odprtokoden sistem, ki ga razvija skupnost in obstaja v številnih različicah, kar omogoča visoko prilagodljivost in varnost, vendar zahteva nekoliko več tehničnega znanja, saj nekateri komercialni programi in igre niso vedno neposredno podprti.

macOS je Applov zaprtokodni sistem, ki je zasnovan izključno za njihove računalnike, kar omogoča zelo dobro optimizacijo in stabilnost, vendar uporabnika veže na dražji Apple ekosistem in omejeno izbiro strojne opreme.
